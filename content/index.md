# AXI：面向 Agent 的操作界面

**规范版本：0.1.0 · 草案。** 本规范将 AI Agent 视为产品的一类正式使用者。Agent 需要完整、可发现、可定位、可验证和可恢复的操作界面，人类需要可理解、可检查与可接管的界面；两者共享同一业务语义与事实。

AXI 在这里表示 **Agent eXperience Interface**。Agent Experience（AX）描述使用体验；Agent-facing interface 描述接口面。本规范没有行业标准地位，也不声称与同名项目存在组织关系。

## 本规范解决什么

Agent 接到目标后，应能回答：

1. **在哪里做？** 找到对应能力、当前对象与准确入口。
2. **能做什么？** 读到精确输入、权限边界与副作用。
3. **现在能做吗？** 区分可执行、禁用、缺项、冲突与等待。
4. **是否做成了？** 得到可验证结果及其适用范围。
5. **中断怎么办？** 沿原任务恢复，不重复产生副作用。

“弹无虚发”的可检验定义是：目标定位正确、输入有效、操作获准、结果可验证、未知可恢复。它不是对模型永不出错的承诺。

## 规范用语

**必须**表示符合性要求；**应当**表示默认做法，偏离时记录理由与证据；**可以**表示可选方案。产品可以有意不支持某类业务，但其已支持的核心任务不得因 Agent 没有视觉控制权限而被无理由阻断。

标准正文完整描述规则；参考文献用于溯源。具体产品的采用清单、源码路径、版本、上线记录和证据属于该产品，不能混入通用标准或把标准图误当实现证明。
