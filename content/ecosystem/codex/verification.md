# Codex 接入验证

本页是采用方的验收方案。AXI仓库本轮交付接口文档、示例与静态站验证，不交付已安装的Codex插件、运行中的MCP服务或已通过各扩展实测的业务应用。官方文档证据见[参考资料](../../references.md#codex-sources)。

## 记录实际环境

| 维度 | 必填证据 |
| --- | --- |
| 宿主 | 产品、表面、精确版本、OS、账号方式、策略与模型 |
| 制品 | 插件来源、版本、实际安装路径/摘要、CLI和SDK版本、UI资源摘要 |
| 连接 | transport、服务合同、当前主体和权限范围；不记录令牌 |
| 项目 | 本地/远程执行位置、获权目录、对象、修订及原操作 |
| 任务 | 成功判据、样本、恢复故障与需要人判断的内容 |
| 性能 | 冷/热分组、首反馈、首个可用结果、总耗时、各层调用数 |

源文件已更新、包已构建、已安装、新会话已发现、工具可调用和业务完成是六种不同证据。

## 按接口的验收矩阵

| 接口 | 正向路径 | 必测负例和降级 |
| --- | --- | --- |
| 插件与Skills | 精确包安装，新会话发现并正确触发方法 | 旧缓存、禁用、依赖缺失、显式/隐式触发负例、更新后重新载入 |
| MCP / 产品CLI | 当前范围内读写并回读同一对象 | 失权、跨账号/项目、CAS冲突、响应丢失、同键恢复、无TTY |
| WebMCP | 当前页面注册、上下文定位和原用例执行 | API缺失、站点拒绝、SPA切换、重复注册、iframe来源、离页后旧工具 |
| DOM / 文字标注 | 点击、拖选、命名与元数据对应目标 | 元数据无效、文字Range失效、shadow DOM差异、请求被拒 |
| 画布surface | 缩放/平移后稳定对象与区域定位 | 空白命中、超时、异步取消后继续命中、对象移除、切对象迟到事件 |
| 标注控件 | 预览、原始对比、重置、保存后重开 | 更新失败不丢旧注册、清理恢复呈现、无API继续普通编辑 |
| MCP App | 初始化、tool-input、tool-result、工具调用与保存 | 待审批输入为空、沙箱失败、迟到回执、切身份、关闭后原任务继续 |
| 原生扩展 | 逐项验证侧栏/面板/设置/深链/文件入口 | 不支持模式、受限计划、缺能力、只保留结构化结果 |
| 文件桥接 | 用户选择文件，读取、编辑和按修订保存 | 撤权、下载过期、错误类型/大小、冲突、丢回执、无文件库 |
| 上下文与消息 | 用户意图下交付选区或请求继续会话 | 错会话、重复提交、已清理请求、不把accepted当已发送 |
| Elicitation | 表单、图片选择及URL接续 | 不支持、拒绝、取消、迟到回答、无TTY结构化缺口 |
| Hooks | 当前脚本获信、事件和范围正确 | 未审核、更新待审、超时/失败、云端模式差异、增加的延迟 |
| SDK / App Server | 原thread继续，增量、审批、结果恢复 | 断连、取消、清理后旧回答、实验字段、业务unknown不被覆盖 |
| MCP Events | 订阅、挑战、签名、去重和回读 | 过期、撤权、退订、重启恢复、无回放、重复事件和自激循环 |

## 图片编辑的完整协作样例

1. CLI/MCP打开原项目的固定图片与修订，本地视图复用同一项目。
2. 页面工具读取真实选区；用户标注意见，确认元数据指向原图和区域。
3. 使用宿主标注时，用户保存并随消息提交；使用普通编辑器时，先持久化意见文件，再把获权引用交给Agent。
4. Agent回读意见与原图，确认待处理项和保持不变的内容；需要模型能力时才渐进连接。
5. 提交一次正式修改任务，记录原操作；未知时查询而非再次生成。
6. 结果写入新版本，与原图并排或滑动比较，逐区域核验，已处理意见不再次提交。
7. 从结果开启下一轮，保留父图、意见修订和任务引用；CLI与网页都能恢复。

多选、右键、撤销、箭头或版本链可以属于产品编辑器。仅实现这些功能，不足以宣称使用了宿主标注API或完整复刻另一产品。

## 性能预算

将等待拆成模型、宿主审查、工具发现、页面命中、业务网络、排队、推理、文件落盘和人工选择。报告回合数与字节数，不用“localhost”“用了WebMCP”或“减少截图”作为更快的证据。

已知合同直达、局部读取、同视图复用、可逆本地预览和长任务事件接续是优化手段；结果正确、权限、修订和恢复是硬门禁。视觉核验保留真实图像，不能以数据库ready状态代替。

## 支持声明

每个扩展分别标记：资料已核实、实现已完成、目标宿主已测、真实任务已测、已发布可安装。标注API的模拟测试只能证明调用和回退逻辑；普通Chromium文档站测试不能证明Codex注入、宿主安全审查、原生表单或消息发送成功。

只有达到对应证据级别后才声明支持，跨宿主的差异继续留在各自适配目录，不修改共同业务事实。
