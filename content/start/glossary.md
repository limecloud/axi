# 术语

本页固定本规范内的含义。产品可以使用自己的领域名称，但不能混淆业务状态与客户端是否知道结果。

| 术语 | 含义 |
| --- | --- |
| Agent | 依据目标选择并调用能力的程序；不假设特定模型 |
| 宿主 / 客户端 | 管理工具连接、身份上下文、模型可见内容与用户交互的应用 |
| 提供方 | 发布能力合同，并通过接入层调用业务服务的一方 |
| 业务服务 | 对资源、权限、修订、写入与操作结果作最终判断的事实源 |
| 能力目录（catalog） | 用于按用途找到动作的轻量索引，不是当前权限清单 |
| 动作合同（action） | 输入、输出、副作用、上下文、恢复与绑定的精确定义 |
| 操作（operation） | 某次有副作用请求的持久执行身份，不等于一次 HTTP 请求 |
| 范围（scope） | 被服务端验证的隔离边界，例如工作区；标识本身不授予权限 |
| 修订（revision） | 用于识别对象版本和条件写入的不透明值；示例使用整数 |
| 幂等键（operation key） | 在规定范围和保留期内，把同一固定输入关联到同一操作的键 |
| 未知（unknown） | 客户端没有足够证据判断操作结果；不是业务失败终态 |
| 回执（result） | 描述当前可观察结果、上下文及恢复入口的结构化数据 |
| 绑定（binding） | 将 AXI 合同映射到既有 CLI、协议或页面接口的方式 |
| Skill | 可按需读取的方法与支持资源；不取代实时权限或工具 Schema |
| 符合性声明 | 精确到规范版本、实现制品、任务和环境的验证声明 |

“Agent Experience（AX）”指整体使用体验；本项目的“AXI”指操作界面合同。它与 Agent 生成给人使用的界面、前后端事件协议分别处理不同层次的问题，见[术语来源](../references.md)。
