# 集成生命周期

本章约束 AXI 与方法、分发、身份、视图及运行载体的协作，不定义新的包格式或授权协议。适用要求覆盖采用方声明支持的载体。

## 组件和来源

**AXI-LIFE-001**：采用方必须声明业务能力、方法、载体适配、原生制品和可选视图的归属、版本及依赖，区分文档支持、参考实现、真实宿主验证和已发布状态；不得从一种载体支持推导另一种已兼容。

**AXI-LIFE-002**：分发必须提供可核对的来源、精确制品及原生安装/启用/卸载路径；需要本地执行或额外权限的组件必须在启用前明确说明。安装完成不得被当作连接、鉴权、授权或任务成功。

## 身份和使用

**AXI-LIFE-003**：连接身份与业务授权必须遵循所选载体的实际合同，复用仍有效的会话并在失效时保留原任务；不得复制其他载体的 Cookie 或凭据来绕过新受众、范围或用户同意。无权、未认证、不可达和未启用必须可区分。

**AXI-LIFE-004**：方法、工具和交互视图必须引用适用的同一任务、对象与合同；方法激活、页面选择、App 上下文更新或建议不得隐式产生新的授权。用户已在视图完成的动作必须先回读，不得重复提交。

## 升级、发布和退出

**AXI-LIFE-005**：升级与发布必须验证实际制品、原生发现、合同/方法/UI 兼容和原操作恢复；新增权限或破坏性副作用不得沿用旧授权静默生效。发布完成必须有目标渠道回读与所声明任务的证据。

**AXI-LIFE-006**：禁用、断开、撤权、卸载和业务取消必须分别表达；退出或退役不得把已提交或未知操作自动标成撤销，也不得在保留义务内破坏原操作恢复。业务数据清理必须有独立明确范围。

## 运行模式与资料生命周期

**AXI-LIFE-007**：采用方必须声明所支持任务的页面位置、内容位置、执行位置、状态Owner及网络/身份依赖；本地绑定不得被当作离线保证，独立本地任务不得被无关远程登录统一阻断。

**AXI-LIFE-008**：跨本地与远程传输或发布必须保留固定内容修订、目的、当前授权及原操作恢复；本机处理、远程执行、结果保存和协作入库不得互相隐含授权或成功。

**AXI-LIFE-009**：采用方必须区分源资料、内部操作记录、可重建缓存、临时结果及正式资料的保留与删除政策；清理不得破坏仍适用的引用、unknown恢复、费用或保留义务，缓存重建不得重发未知写入。

**AXI-LIFE-010**：采用本地工作区的实现必须公布目录选择、默认位置及其OS解析规则；不得因用户取消或指定路径失败而静默另存，不得将凭据、临时目录和用户项目混为同一存储。

**AXI-LIFE-011**：首次使用应当从用户目标和已有任务渐进开始，复用适用默认值与有效上下文；实现不得以无关运行模式选择或远程登录阻断声明支持的本地任务。远程处理、付费、存储及共享的新增影响必须在对应动作前说明并取得适用授权，不能由默认值隐含。

**AXI-LIFE-012**：需要用户决定时，实现应当优先采用宿主实际支持的原生选择或输入交互，合并相关缺项并复用已有决定；必须处理接受、拒绝、取消和不支持，保留原任务。机器模式不得等待不可见终端输入，选择结果不得被当作目录权限或新增副作用授权。

设计与验证见[本地工作区实践](../../practices/local-workspaces.md)。这些要求不新增核心JSON字段，不强制全部采用方实现离线或相同文件格式。

## 扩展载体

新宿主复用这些生命周期不变量，并公布原生映射、差异、降级和测试矩阵。原生 API 的调用名、文件位置或协议版本不属于 AXI 核心字段。实现步骤见[新载体适配](../../ecosystem/adapters.md)，阶段指南见[生命周期总览](../../lifecycle/index.md)。
