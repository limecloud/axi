# 变更记录

本页记录规范与文档的可观察变化。实现是否发布或采用由各产品的制品与证据声明决定。

## 0.2.1 草案 2026-11-10

- 草案版本递增至0.2.1，同步规范目录、Schema标识、示例、参考提供方与校验入口；调用中的`spec_version`使用`0.2.1`。
- 按宿主分设Codex、Claude Code、WorkBuddy和DSH目录，分开记录资料与运行验证范围。
- Codex新增开放接口、插件与连接、WebMCP、Browser Annotation API、原生界面与文件、CLI/SDK/App Server和验证章节。
- 区分普通网页、MCP App沙箱和本地客户端，补充11类OpenAI原生扩展、文件/消息桥接、结构化选择、Hooks与MCP Events的边界和降级。
- 增加架构、鉴权、页面调用、标注交付和自有客户端时序，补齐逐接口负例与性能验收；核心字段、状态与行为要求不变。

## 0.2.0 草案 2026-11-08

- 增加本地工作区、普通文件与嵌入式事务状态的分工，补齐独立本地/在线/协作拓扑、时序和目录选择流程。
- 补充人类TTY交互、非TTY/机器模式、OS默认目录、离线资源、loopback安全和分级保留的生命周期要求；核心JSON结构未变，不声明新增运行实现。
- 补充渐进首次使用、宿主原生选择、云端能力/存储/协作的独立用途，以及跨CLI/MCP/视图的预算与性能证据要求。
- 将概念、版本化规范、开发指南、实践与参考分开组织。
- 引入 catalog、action、result、page、batch 的 JSON 表示和 Draft 2020-12 Schema。
- 固定状态、错误、上下文、授权、原操作恢复、分页、只读批量、等待与取消语义。
- 加入要求编号、字段参考、CLI/MCP/浏览器绑定指南，以及版本和扩展边界。
- 增加离线合同检查、本地审批参考提供方及故障行为测试。
- 从同一导航和规范生成 Markdown 入口、文档索引与要求索引。

兼容说明：早期 0.1.0 文稿中的示意字段未形成机器合同。本版替换这些示意，不能声称与旧 JSON 线格式兼容。旧版根页面仍作为导读入口，其精确规则统一指向当前版本目录。
